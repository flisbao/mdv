Referência da API Trocapay

Pressione Ctrl + K para buscar na documentação.

EstávelBeta: pix parcelado

A API Trocapay permite criar cobranças, consultar pagamentos e receber eventos em tempo real. Todas as respostas são JSON e seguem o padrão REST.

Autenticação

Cada requisição precisa do cabeçalho Authorization com a chave da sua conta. As chaves de teste começam com sk_test.

Atenção

Nunca exponha a chave secreta no navegador.

Dica

Ambientes de teste usam chaves com o prefixo sk_test e não geram cobranças reais.

Criar cobrança

Uma cobrança é criada com um POST para o endpoint abaixo. O corpo aceita os parâmetros da tabela.

# Cria uma cobrança de R$ 49,90
curl https://api.trocapay.example/v2/cobrancas \
  -H "Authorization: Bearer sk_live_xxx" \
  -d "valor=4990" \
  -d "descricao=Assinatura mensal"

Parâmetros

ParâmetroTipoObrigatórioDescrição
valorinteirosimValor total da cobrança em centavos
moedatextonãoCódigo ISO 4217. O padrão é BRL.
descricaotextonãoTexto exibido na fatura do cliente.
parcelasinteironãoDe 1 a 12. O padrão é 1.

Valores em centavos

Nunca envie valores com ponto decimal. Um valor de R$ 49,90 é enviado como 4990.

Resposta

{
  "id": "cob_01HZX",
  "status": "pendente",
  "valor": 4990,
  "pago": false
}

Exemplo com Node.js

import { Trocapay } from 'trocapay';
const pay = new Trocapay(process.env.TROCAPAY_KEY);
await pay.cobrancas.criar({ valor: 4990 });

Webhooks

Os eventos são enviados por POST para a URL que você cadastrou no painel.

cobranca.pago
Disparado quando o pagamento é confirmado pelo banco.
cobranca.vencida
Disparado quando o prazo de pagamento termina sem quitação.
reembolso.criado
Disparado quando um estorno é solicitado pelo lojista.

Erros

Erros usam os códigos HTTP padrão. O corpo traz um campo codigo legível por máquina.

HTTPCódigoSignificado
400parametro_invalidoAlgum campo não passou na validação.
401chave_invalidaA chave não existe ou foi revogada.
429limite_excedidoMuitas requisições em pouco tempo.

Limites

Cada conta pode fazer até 100 requisições por segundo. Acima disso, a API responde com 429.

        Por que ownership existe                                                
        ────────────────────────────────────────────────────────────────        
                                                                                
        Rust garante segurança de memória sem coletor de lixo. A regra          
        central é simples:                                                      
                                                                                
        ▌                                                                       
        ▌    Cada valor tem exatamente um dono, e quando o dono sai             
        ▌    de escopo, o valor é liberado.                                     
        ▌                                                                       
        ▌    Livro oficial da linguagem, capítulo 4                             
        ▌                                                                       
                                                                                
        ╭────────────────────────────╮   ╭────────────────────────────╮         
        │                            │   │                            │         
        │    Na prática              │   │    Dica                    │         
        │    • Atribuir um String    │   │    Use clone() quando      │         
        │      move a posse.         │   │    precisar de uma         │         
        │    • O original deixa      │   │    cópia independente.     │         
        │      de ser usável.        │   │                            │         
        │                            │   │                            │         
        │                            │   │                            │         
        ╰────────────────────────────╯   ╰────────────────────────────╯

        Empréstimos imutáveis                                                   
        ────────────────────────────────────────────────────────────────        
                                                                                
        Uma referência &T empresta o valor sem tomar posse dele.                
                                                                                
        • Várias referências imutáveis podem coexistir.                         
        • Nenhuma delas pode modificar o valor.                                 
        • O dono continua responsável pela liberação.                           
                                                                                
                                                                                
            // várias leituras ao mesmo tempo                                   
            let a = &texto;                                                     
            let b = &texto;

        Empréstimos mutáveis                                                    
        ────────────────────────────────────────────────────────────────        
                                                                                
        Só pode existir um empréstimo mutável por vez. Essa restrição           
        evita corridas de dados.                                                
                                                                                
        ╭────────────────────────────╮   ╭────────────────────────────╮         
        │                            │   │                            │         
        │    Permitido               │   │    Recusado                │         
        │    Um &mut sozinho,        │   │    Um &mut enquanto        │         
        │    usado e encerrado.      │   │    existe um & ainda       │         
        │                            │   │    usado.                  │

        Tempo de vida                                                           
        ────────────────────────────────────────────────────────────────        
                                                                                
         Lifetimes descrevem por quanto tempo uma referência é válida.          
                                                                                
                                                                                
            fn maior<'a>(x: &'a str, y: &'a str) -> &'a str {                   
                if x.len() > y.len() { x } else { y }
